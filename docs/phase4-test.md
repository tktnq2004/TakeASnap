# Phase 4 — Phiếu kiểm tra trên máy thật

Cách điền: mỗi ô máy ghi `đạt`, `lỗi` hoặc `—` (không áp dụng). Mục lỗi thì ghi ở cột Ghi chú đã làm gì và thấy gì.

| Máy | Phiên bản |
|---|---|
| iPhone | iPhone 15 Pro Max · Expo Go 58 · iOS |
| Android | Pixel_8a emulator · Expo Go 58 · Android |

Ngày thử: 

## 1. Mở app và quyền

| # | Thao tác | Kỳ vọng | iPhone | Android | Ghi chú |
|---|---|---|---|---|---|
| 1.1 | Xóa Expo Go khỏi danh sách gần đây, mở app lần đầu (hoặc thu hồi quyền camera trong Cài đặt máy) | Hiện thẳng hộp thoại xin quyền camera của máy, không có màn giải thích riêng | | | |
| 1.2 | Từ chối quyền camera | Màn tối với một câu "SnapShot cần camera để chụp theo pose." và một nút (Cho phép dùng camera hoặc Mở Cài đặt) | | | |
| 1.3 | Cho phép quyền | Vào thẳng Camera | | | |
| 1.4 | Nhìn chữ ở mọi màn | Chữ Nunito, không còn chữ kiểu cũ; màn sáng nền trắng xanh, Camera nền tối | | | |

## 2. Camera — thanh trên

| # | Thao tác | Kỳ vọng | iPhone | Android | Ghi chú |

| 2.4 | Chạm Thước | Thước cân bằng bật / tắt; vạch giữa vàng khi máy lệch, xanh và rung nhẹ khi thẳng | | | |
| 2.5 | Chạm Tỉ lệ | 3:4 → 9:16 → 1:1, khung ngắm bo góc đổi theo | | | |
| 2.6 | Chạm Mở thêm | Bảng thả xuống mượt (cao dần, hàng trượt xuống), mũi tên xoay; chọn thẳng giá trị Đèn flash, Hẹn giờ, Lưới | | | |
| 2.7 | Chạm ra ngoài bảng hoặc chạm lại mũi tên | Bảng kéo lên mượt rồi biến mất | | | |

| # | Thao tác | Kỳ vọng | iPhone | Android | Ghi chú |
