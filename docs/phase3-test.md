# Phase 3 — Phiếu kiểm tra trên máy thật

Cách điền: mỗi ô máy ghi `đạt`, `lỗi` hoặc `—` (không áp dụng). Mục lỗi thì ghi ở cột Ghi chú đã làm gì và thấy gì.

| Máy | Phiên bản |
|---|---|
| iPhone | iPhone 15 Pro Max · Expo Go 58 · iOS |
| Android | Pixel_8a emulator · Expo Go 58 · Android |

Ngày thử: 

## 1. Thêm ảnh và chọn người

| # | Thao tác | Kỳ vọng | iPhone | Android | Ghi chú |
|---|---|---|---|---|---|
| 1.1 | Thêm ảnh có **một** người | Danh sách được thay bằng ảnh mờ, đáy có dòng trạng thái; xong thì mở Chỉnh pose, không hỏi chọn người | | | |
| 1.2 | Thêm ảnh có **hai, ba người đứng tách nhau** | Hiện màn "Chọn người", mỗi người có viền riêng | | | |
| 1.3 | Chạm vào từng người | Chạm lần 1 phủ cam, chạm lần 2 bỏ chọn; có rung nhẹ | | | |
| 1.4 | Chọn một người → "Dùng người đã chọn" | Pose chỉ có người đó; nét mặt là mặt của người đó | | | |
| 1.5 | "Chọn tất cả" | Pose có mọi người | | | |
| 1.6 | Bấm X ở màn Chọn người | Về Thư viện, không có pose mới trong "Pose của bạn" | | | |
| 1.7 | Ảnh có hai người **đứng sát, chạm nhau** | Hai người thành một vùng (giới hạn đã biết). Ghi lại để biết có hay gặp không | | | |

## 2. Lỗi

| # | Thao tác | Kỳ vọng | iPhone | Android | Ghi chú |
|---|---|---|---|---|---|
| 2.1 | Thêm ảnh không có người (phong cảnh, đồ vật) | Báo "Không tìm thấy người…", có nút "Chọn ảnh khác" mở lại thư viện ảnh | | | |
| 2.2 | Thêm ảnh người rất nhỏ, ở xa | Báo "Người trong ảnh quá nhỏ…", có "Chọn ảnh khác" | | | |
| 2.3 | (Chỉ khi máy chưa tải bộ tách người) tắt mạng rồi thêm ảnh | Báo "Chưa tải được bộ tách người…", có "Thử tải lại" | | | |

## 3. Sửa nét

| # | Thao tác | Kỳ vọng | iPhone | Android | Ghi chú |
|---|---|---|---|---|---|
| 3.1 | Mở Chỉnh pose, chọn tab "Sửa nét" | Có [Thêm \| Xóa], nút hoàn tác và làm lại (đang mờ), thanh Cỡ cọ, dòng hướng dẫn | | | |
| 3.2 | Chọn Thêm, tô ra ngoài người | Nét cam mờ hiện ngay theo ngón tay; nhấc tay thì viền và lớp phủ nở ra theo vùng vừa tô | | | |
| 3.3 | Chọn Xóa, tô lên người | Nét đỏ mờ; nhấc tay thì vùng đó bị bỏ khỏi người | | | |
| 3.4 | Kéo Cỡ cọ từ 8 đến 64 px | Nét vẽ to nhỏ đúng theo số | | | |
| 3.5 | Hoàn tác vài lần rồi làm lại | Viền quay về đúng từng bước; hết bước thì nút mờ đi | | | |
| 3.6 | Vẽ liên tục, nhấc tay | Vẽ không giật; viền vẽ lại gần như ngay khi nhấc tay | | | |
| 3.7 | Sửa nét rồi "Lưu pose", mở lại pose đó | Viền đã sửa vẫn còn; ô trong Thư viện và overlay trên Camera cũng theo viền mới | | | |
| 3.8 | Sửa nét một **pose mẫu** rồi lưu | Thêm một bản vào "Pose của bạn" với viền đã sửa; pose mẫu gốc không đổi | | | |
| 3.9 | Xóa gần hết người rồi lưu | Báo "Vùng người còn quá nhỏ", không lưu | | | |

## 4. Chế độ máy bay

| # | Thao tác | Kỳ vọng | iPhone | Android | Ghi chú |
|---|---|---|---|---|---|
| 4.1 | Bật chế độ máy bay, tắt hẳn app rồi mở lại | App mở bình thường, Camera chạy | | | |
| 4.2 | Chụp theo pose, lưu ảnh | Như khi có mạng | | | |
| 4.3 | Thêm ảnh từ máy, chọn người, sửa nét, lưu | Như khi có mạng (bộ tách người đã tải từ trước) | | | |
